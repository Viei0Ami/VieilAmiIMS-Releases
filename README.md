# 家庭物品管理系统 - 无限探索版

**英文/项目名：** VieilAmiIMS

**当前版本：** RC1-1.0.02

**当前状态：** 公开测试版 / Release Candidate

VieilAmiIMS 是一款用于整理、查询和管理家庭物品信息的 Windows 桌面应用。当前仓库仅用于公开发布安装包、测试说明、更新记录和用户反馈，不包含源码，也不包含 private 仓库内容。

## 功能简介

- 首页统计：快速了解物品数量、分类、位置等概览信息。
- 物品查询：按名称、标签、位置等信息查找物品。
- 新增编辑：录入和维护物品的基础信息。
- 图片：为物品添加图片，便于识别和整理。
- 附件：保存与物品相关的文件资料。
- 标签：通过标签对物品进行灵活分类。
- 位置：记录物品所在房间、柜子或收纳位置。
- 字典：维护常用分类、位置、状态等基础数据。
- Timeline：查看物品相关操作和变化记录。
- PDF 导出：导出物品信息或清单。
- 标签打印：用于生成和打印物品标签。
- 备份恢复：支持数据备份和恢复。
- 多语言基础支持：包含中文、英文、日文、繁体中文资源基础。
